"A workflow manager that helps people think together, learn through action, and convert uncertainty into meaningful progress." Product vision

The core idea

A note records information. A cycle records progress.

Cycle separates the two on purpose. Every entry gets a role — an observation, a need, an assumption, evidence, an idea, a decision, an action, a risk, or a reflection — so the system can always answer: what did we learn, what changed, what did we decide, and what happens next.

Core workflow

Eight stages, one loop.

The path is guided, not linear. A failed test can send a challenge back to Define or Ideate instead of closing it out as a loss.

Empathize

Understand people and context

Capture users, observations, interviews, frustrations, and needs.

Output: user insights

Define

Frame the real problem

Identify patterns and write a problem statement.

Output: clear challenge

Ideate

Explore possible solutions

Generate, compare, and combine ideas.

Output: solution concepts

Prototype

Make an idea tangible

Create a rough version, flow, mockup, or process.

Output: prototype

Test

Learn from feedback

Record reactions, evidence, and failures.

Output: validated learning

Decide

Choose what to do next

Evaluate options against criteria.

Output: decision

Execute

Turn the decision into work

Create tasks, owners, milestones, and dependencies.

Output: action plan

Reflect

Improve the process

Review results and lessons.

Output: new insights

Not strictly linear. Any stage can send the challenge backward. A prototype with weak feedback returns to Ideate; a decision with no evidence returns to Empathize.

Main objects

A network of thinking, not a pile of pages.

Instead of generic notes, Cycle uses structured objects that link to each other across the workflow.

Challenge

The problem or opportunity being explored.

Person / stakeholder

Someone affected by the challenge.

Insight

An observation or meaningful learning.

Problem statement

A clearly framed need.

Idea

A possible response to the problem.

Prototype

A tangible representation of an idea.

Experiment

A test designed to learn something.

Decision

A selected direction and its rationale.

Task

An actionable next step.

Evidence

Feedback, metrics, documents, or observations.

Reflection

What should change in the next cycle.
