====================================
  Go Together - Trip Planning App
====================================

Welcome! This app helps you plan trips with friends.

QUICK START:
1. Make sure this folder contains:
   - GoTogetherApp.exe
   - .env file
2. Double-click GoTogetherApp.exe
3. Register with your email
4. Start planning trips!

====================================
           USER ROLES
====================================

Choose one when registering:

HOST:
- Create trip plans
- Set location, budget, duration
- Add sections (activities)
- View friend responses
- Needs unique Host ID (e.g., "TravelHost2024")

FRIEND:
- Browse plans from HOST friends
- Respond with Accept/Reject
- Propose custom budget
- Mark sections you can't attend
- Exchange contact info with HOST

====================================
         GETTING STARTED
====================================

STEP 1: REGISTER
- Open the app
- Click "Register"
- Enter your details
- Choose HOST or FRIEND
- Click Register

STEP 2: ADD FRIENDS
- Click "Friends" button
- Enter friend's email address
- Click "Add"
- They must also be registered!

STEP 3: CREATE OR BROWSE PLANS
HOST:
- Click "Create New Plan"
- Fill in details
- Add sections (comma-separated)
- Click "Create Plan"

FRIEND:
- Plans from your HOST friends appear automatically
- Click "Respond to Plan"
- Accept or Reject
- Set your budget
- Submit response

====================================
          KEY FEATURES
====================================

✅ Cloud-based - Access from anywhere
✅ Real-time updates - See plans instantly
✅ Secure - Passwords encrypted
✅ Host ID - Easily identify plan creators
✅ X-Marks - Mark sections you can't attend
✅ Notifications - Get notified of responses
✅ Phone exchange - Share contacts after approval

====================================
        TROUBLESHOOTING
====================================

App won't start?
- Make sure .env file is in the same folder
- Check internet connection
- Run as Administrator (right-click app)

Can't see plans?
- Make sure you've added friends
- HOST friends must create plans first
- Try closing and reopening the app

Error connecting to database?
- Check your internet connection
- Verify .env file is present
- Contact the person who shared the app

Can't register?
- Email must be unique
- For HOST: Host ID must be unique
- Check internet connection
