# Advance Projects

A curated collection of apps, browser tools, and utilities. Each project lives in its own folder and has a project-specific README with setup notes.

- [Go Together](apps/go-together/) ? Python application and desktop packaging sources.

- [Document RAG](apps/document-rag/) ? document retrieval application.
- [Shopping Web](apps/shopping-web/) ? Bagisto based storefront/mobile project.

## Safety and setup

Secrets, local environment files, executables, dependency folders, build output, and duplicate archives are intentionally excluded. Add local credentials to an untracked `.env` file using the variables documented by each project.
